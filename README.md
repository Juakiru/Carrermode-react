# Gestión de Torneos Deportivos

Proyecto desarrollado para la Evaluación 1 de Desarrollo de Aplicaciones Web.

Tema del proyecto: Gestión de Torneos Deportivos: Equipos, partidos, resultados y tabla de posiciones.

Esta pagina, esta enfocada hacia las personas que sean fanaticas de cualquier deporte, y puedan estar al tanto de las ligas mas famosas de dichos deportes con sus equipos, tablas de cada liga y sus calendarios de encuentros.

Implementamos unas funciones de filtrado multideporte con elección entre Fútbol, Básquetbol y Vóleibol, mostrando únicamente las competiciones asociadas a cada deporte tambien implementamos unos logos adaptados a cada liga y que se muestre en el encabezado para adaptar su avatar automáticamente al balón del deporte seleccionado o al escudo oficial de la liga activa. Incluimos tambien una simulación de datos con manejo de estados de carga con temporizadores controlados mediante `useEffect` para simular la carga de datos de una API externa. Agregamos igual una tabla de posiciones dinámica con cálculo de clasificaciones ordenadas descendentemente por puntaje acumulado otro detalle que agregamos fue que a los clubes les dimos vista dedicada para cada equipo que expone estadísticas globales, historial de partidos y agregamos a un club su nómina de jugadores categorizada por posición (Arqueros, Defensas, Mediocentros y Delanteros) y como ultima funcionalidad aplicamos a la pagina un diseño responsivo con una interfaz fluida adaptable a monitores, tablets y teléfonos celulares.

Tecnologías utilizadas: React, TypeScript, Vite y CSS
